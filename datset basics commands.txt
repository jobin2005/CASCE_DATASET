Phase 1: Start the Environment
First, build and start the Docker container in the background. This will start PostgreSQL and mount your scripts into the container.

bash
cd "/home/jobin/Desktop/Mini Project_Reserach/Dataset"
docker-compose up -d --build
Wait a few seconds for it to start up, then enter the container's shell:

bash
docker exec -it casce_environment bash
(You are now inside the container for all the remaining steps below.)

Phase 2: Build & Load Telemetry
Navigate to the mounted workspace and compile the custom C extension we wrote:

bash
cd /dataset_workspace/pg_telemetry_extension
make && make install
Phase 1.5: Setup the Database
Run the script to download and import the DVD Rental dataset:

bash
cd /dataset_workspace
./setup_db.sh
Now, enable the telemetry extension on the DVD rental database so it starts recording queries:

bash
psql -U admin -d dvdrental -c "CREATE EXTENSION pg_telemetry;"
Phase 3 & Phase 4: Start Telemetry & Run Workloads
Start our central collector in the background (this automatically kicks off the eBPF kernel tracing):

bash
./collector.py &
(Wait 2 seconds to ensure eBPF compiles and attaches to the kernel tracepoints).

Now, generate the background noise/normal traffic (100,000 queries):

bash
./normal_workload.sh
Once that finishes, run your attack simulations:

bash
./attack_workload/attack_exfiltration.sh
./attack_workload/attack_sabotage.sh
./attack_workload/attack_privilege_abuse.sh
./attack_workload/attack_reverse_shell.sh
Once the attacks are done, stop the collector by pressing Enter to get a fresh prompt, then typing fg and pressing Ctrl+C.

Phase 5, 6, & 7: Label, Validate, and Freeze
Now that all data is recorded, run your Python processing scripts to label the attacks and validate PID integrity:

bash
./generate_labels.py
./dataset_validator.py
If the validator says VALIDATION SUCCESSFUL, run the final script:

bash
./freeze_dataset.sh
